# 총공세 2일차 — PC 상태 기록 타임라인

## 1. 작업 목적

PC의 주요 자원 상태를 조회하고, 조회 결과와 측정 시각을 시간순으로 확인할 수 있도록 학생 확장 화면에 PC 상태 기록 타임라인을 추가한다.

이 기능은 PC 상태 조회 응답을 바탕으로 CPU, 메모리, 디스크 상태를 표시한다. 측정에 실패하거나 응답을 검증할 수 없는 경우에는 임의의 수치나 예시 값을 표시하지 않고 확인 불가 상태로 구분한다.

## 2. 측정 항목

다음 세 가지 항목을 표시한다.

- **CPU:** 사용률(%)
- **메모리:** 사용량 및 전체 용량(GB)
- **디스크:** 남은 용량 및 전체 용량(GB)

각 항목의 값과 단위가 유효한 경우에만 측정값으로 표시한다. 값이 없거나 형식이 올바르지 않은 경우에는 확인 불가로 표시한다.

## 3. 기록 타임라인

- PC 상태 조회 응답의 측정 시각(`measuredAt`)을 사용한다.
- 측정 기록은 조회 시각을 기준으로 최신 항목부터 표시한다.
- CPU, 메모리, 디스크 항목을 각각 확인할 수 있다.
- 기록 종류 필터에서 전체 또는 개별 항목을 선택할 수 있다.
- 기록 건수와 조회 횟수를 표시한다.
- 한 번의 조회에서 세 가지 측정 항목을 함께 기록한다.

## 4. 다시 측정하기

`PC 상태 다시 측정` 버튼을 제공한다.

버튼을 누르면 `/api/pc/status`에 새 조회 요청을 보내며, 응답을 검증한 뒤 기록에 추가한다.

조회 중에는 중복 요청을 방지하기 위해 버튼을 비활성화한다. 조회 실패 또는 응답 검증 실패 시 해당 결과를 정상 측정 기록으로 추가하지 않는다.

## 5. 실제 측정값과 확인 불가의 구분

다음 기준을 적용한다.

- 실제 조회 응답이 정상적으로 확인된 경우에만 측정 기록에 추가한다.
- CPU 사용률은 0~100% 범위인지 확인한다.
- 메모리와 디스크 용량은 숫자 및 전체 용량과의 관계를 확인한다.
- 권한 거부, 지원하지 않는 운영체제, 조회 시간 초과, 잘못된 응답 등의 경우 원인에 따라 확인 불가로 표시한다.
- 측정 실패를 정상적인 0으로 표시하지 않는다.
- 예시 데이터나 임의의 측정값을 실제 PC 측정 결과처럼 표시하지 않는다.

## 6. 기록 보관 범위

PC 상태 기록은 현재 앱 실행 중 메모리에 보관한다.

- 최대 40회의 조회 기록을 유지한다.
- 새 기록은 기존 기록보다 앞에 추가한다.
- 앱을 종료하면 메모리에 보관된 기록은 사라진다.
- 별도의 영구 저장이나 서버 저장 기능을 구현한 것으로 간주하지 않는다.

## 7. 기존 기능과의 관계

기존 제공 화면 및 PC 상태 조회 기능을 재사용한다.

- 기존 `renderStatus()` 화면에서 PC 상태 타임라인을 표시한다.
- 기존 `/api/pc/status` 조회 경로를 사용한다.
- PC 측정 기능 자체나 서버 코드를 임의로 변경하지 않는다.
- 기존 보호 현황, 업무 앱, 보안 기록 등의 기능을 대체하지 않는다.

## 8. 확인 및 검증 항목

다음 항목을 직접 확인한다.

1. 보호 현황 화면에 PC 상태 기록 타임라인이 표시되는가?
2. CPU, 메모리, 디스크 항목이 구분되어 표시되는가?
3. 측정 시각이 함께 표시되는가?
4. 전체 및 개별 항목 필터가 작동하는가?
5. 다시 측정 버튼을 눌렀을 때 새 조회가 이루어지는가?
6. 조회 실패 시 실패 사실이 표시되고 가짜 측정값이 추가되지 않는가?
7. 앱 실행 중 기록이 최대 40회까지 유지되는가?
8. 앱 종료 후 기록이 사라지는 보관 범위가 명확하게 안내되는가?

실제 측정 결과와 검증 결과는 실행 후 확인한 내용만 기록한다. 실행하지 않은 항목을 통과한 것으로 표시하지 않는다.
